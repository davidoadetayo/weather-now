# Weather Now 🌤️

A simple, responsive weather app built with HTML, CSS, and JavaScript.  
Displays current weather and a 7-day forecast for any location using the WeatherAPI.

---

## Features

- Search for any location to get current weather
- Displays temperature, humidity, and "feels like" temperature
- 7-day forecast with icons and temperatures
- Responsive design for desktop and mobile
